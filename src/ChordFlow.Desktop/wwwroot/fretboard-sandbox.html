Fretboard render component — sandbox

Fixtures are hand-fed marker models. Voicing is one circle per string (the chord case). C-major scale shows many markers per string as squares — the generalization the voicing model can't express. Layered overlay mixes all four shapes (ring root, circle chord tones, square scale, diamond target) and passes an override per-interval palette, so the legend keys on interval tokens. Grid cell shows a per-cell title + a synthetic id with a Copy-id button, and the per-cell orientation toggle hidden (controls.orientation:false) as it is inside a VoicingsR grid.
